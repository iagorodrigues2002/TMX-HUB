# Home gateway breakdown

Add a compact provider table to the account home overview using its existing financial query and date filters. Group normalized order provider within each owner, only across explicitly accessible/enabled offers. Counts distinguish all approved transactions, fronts and upsells; gross BRL uses stored conversion or the existing FX cache. Missing conversion values carry a visible warning rather than fabricated revenue. Gross approvals include purchases subsequently reversed, consistent with overview finance; no new fee assumptions.

SyzePay company receipts remain a separate pending-events row without monetary totals, and are disclosed only to their connection owner (not invited offer members). Keep financial privacy masking and loading/error handling. No writes to orders, receipts or deliveries.
